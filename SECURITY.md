# Security policy

## Supported versions

Security fixes are provided for the latest published version of Tabel.

## Reporting a vulnerability

Use GitHub private vulnerability reporting from the repository Security tab. Do not include private URLs, exported Tabel data, credentials, or personal information in a public issue.

Include:

- The affected Tabel and Chrome versions.
- Clear reproduction steps.
- The expected and actual behavior.
- A minimal proof of concept that contains no personal data.

The report will be reviewed before any public disclosure.
