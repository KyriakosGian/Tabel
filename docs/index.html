Installation guide

Install Tabel manually from the official GitHub Release.

Download Tabel

Download the Tabel 1.6.0 ZIP from GitHub.

Extract the archive

Extract the ZIP to a permanent folder on your computer. Chrome needs this folder to run Tabel.

Open Extensions

Open chrome://extensions/ in Chrome and enable Developer mode.

Load Tabel

Select Load unpacked and choose the extracted folder that contains manifest.json. You can then pin Tabel to the toolbar.

Your data stays under your control

Tabel does not use a developer-operated server, advertisements, or tracking tools.

Frequently asked questions

Core information before installing Tabel.

Do I need a Tabel account?

No. The extension works with Chrome's built-in storage features.

Are my tabs sent to the developer?

No. Tabel has no developer-operated server. Synchronization uses only chrome.storage.sync.

Can I keep a backup?

Yes. You can export and import a JSON file from Settings.

Which tabs are saved?

Tabel saves tabs only after you use the extension icon, Save Tabs, or a context menu command. Dashboard settings control whether pinned and audible tabs are included.
