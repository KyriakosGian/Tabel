Chrome Extension

Λιγότερη ακαταστασία. Περισσότερος έλεγχος στις καρτέλες σας.

Το Tabel μετατρέπει τις ανοιχτές καρτέλες σε οργανωμένες ομάδες που μπορείτε να αναζητήσετε, να ταξινομήσετε, να συγχρονίσετε και να επαναφέρετε.

Πώς λειτουργεί

Τρία βήματα από την ακαταστασία σε ένα οργανωμένο Dashboard.

Πατήστε το Tabel

Η επέκταση συλλέγει μόνο τις μη καρφιτσωμένες καρτέλες του ενεργού παραθύρου.

Οργανώστε τις ομάδες

Μετονομάστε, ταξινομήστε, κλειδώστε και μορφοποιήστε τις αποθηκευμένες ομάδες.

Επαναφέρετε ό,τι χρειάζεστε

Ανοίξτε μία σελίδα ή ολόκληρη ομάδα όταν έρθει η στιγμή να συνεχίσετε.

Οι βασικές λειτουργίες

Οργάνωση καρτελών χωρίς λογαριασμό Tabel και χωρίς εξωτερικό διακομιστή.

Ομαδοποίηση

Αποθηκεύστε τις ενεργές καρτέλες ενός παραθύρου σε μία οργανωμένη ομάδα.

Αναζήτηση και ταξινόμηση

Βρείτε γρήγορα μια σελίδα και οργανώστε ομάδες και καρτέλες με μεταφορά.

Επαναφορά

Ανοίξτε μία καρτέλα ή ολόκληρη ομάδα μόνο όταν τη χρειάζεστε.

Συγχρονισμός Chrome

Συγχρονίστε τις αποθηκευμένες ομάδες μέσω του chrome.storage.sync.

Εισαγωγή και εξαγωγή

Δημιουργήστε τοπικό αντίγραφο ασφαλείας σε JSON και επαναφέρετέ το.

Προσαρμογή

Επιλέξτε θέμα, διαφάνεια, πλάτος και χρώμα για κάθε ομάδα.

Τα δεδομένα σας παραμένουν υπό τον έλεγχό σας

Το Tabel δεν χρησιμοποιεί δικό του διακομιστή, διαφημίσεις ή εργαλεία παρακολούθησης.

Συχνές ερωτήσεις

Οι βασικές πληροφορίες πριν εγκαταστήσετε το Tabel.

Χρειάζεται λογαριασμός Tabel;

Όχι. Η επέκταση λειτουργεί με τις δυνατότητες αποθήκευσης του Chrome.

Αποστέλλονται οι καρτέλες στον δημιουργό;

Όχι. Δεν υπάρχει διακομιστής Tabel. Ο συγχρονισμός γίνεται μόνο μέσω του chrome.storage.sync.

Μπορώ να κρατήσω αντίγραφο ασφαλείας;

Ναι. Από τις ρυθμίσεις μπορείτε να εξαγάγετε και να εισαγάγετε αρχείο JSON.

Ποιες καρτέλες αποθηκεύονται;

Μόνο οι μη καρφιτσωμένες καρτέλες του ενεργού παραθύρου, αφού αποδεχτείτε την ενημέρωση απορρήτου και πατήσετε το εικονίδιο.

Το Tabel έρχεται στο Chrome Web Store

Η δημόσια έκδοση βρίσκεται στο τελικό στάδιο δοκιμών και προετοιμασίας.
