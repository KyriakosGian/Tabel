Support

Basic troubleshooting steps for Tabel.

The extension does not save tabs

  1. Open the Dashboard and accept the privacy notice.
  2. Make sure the tabs are not pinned.
  3. Check chrome://extensions/ for errors.
  4. Click Reload on the Tabel card and try again.

Data does not appear on another device

  1. Sign in to the same Google Account in both Chrome installations.
  2. Enable extension synchronization.
  3. Keep the Dashboard open for a few seconds.

Create a backup

Open Settings, choose Export Data, and save the JSON file in a safe location.

Report a problem

Create a bug report on GitHub. Include the Chrome version, Tabel version, and the steps that caused the issue. Do not include private URLs or personal data.
