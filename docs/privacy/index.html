Privacy Policy

Last updated: October 12, 2026

Tabel works without a Tabel account, advertising, or a developer-operated server.

1. Scope

This policy explains how the Tabel extension for Google Chrome collects, uses, stores, and shares data.

2. Data processed by Tabel

When a user chooses to organize open tabs through the extension action, Dashboard, or context menu, Tabel processes:

  • the URL of each selected tab or link
  • the page title
  • user-created group names, sorting choices, and display preferences
  • extension settings such as theme and startup behavior

Website icons are displayed through Chrome's favicon API and are not stored or synchronized by Tabel. Tabel does not read passwords, cookies, form contents, or full webpage content.

3. When collection occurs

After the privacy notice is accepted, Tabel reads tab data when the user clicks the extension icon, opens Save Tabs in the Dashboard, or uses a Tabel context menu command. Save Tabs reads the URLs and titles of open tabs to display the selection list. Only the tabs or links chosen for saving are retained. The extension does not continuously record browsing history.

4. Purpose

Data is used only to save, display, search, sort, sync, and restore the tabs that the user chooses to organize.

5. Storage and synchronization

Groups, tabs, deletion records, and verified safety backups are stored locally using IndexedDB. Settings, sync status, a context-menu group index, and temporary operational data use chrome.storage.local. Local Only keeps changes on this device. Chrome Sync uses chrome.storage.sync, which requires the same extension ID and Google Account with Chrome sync enabled and provides approximately 100 KB for data, deletion records, and metadata.

Google processes data sent through Chrome Sync when synchronization is enabled. Local links remain available if an upload fails. The shared public extension key is not a credential. Tabel has no developer-operated server and does not give its developer access to users' stored data.

6. Data sharing

Tabel does not sell or rent data, use it for advertising or tracking, or send it to a developer-operated server. Synchronization uses Google Chrome Sync when enabled by the user.

7. Retention and deletion

Saved tabs remain until removed through restoration, deletion, or import replacement. Deletion records contain identifiers and timestamps so removals can reach other devices. They remain for at least 90 days and until all known devices acknowledge them. Some may remain longer. Clean Unused Sync Data removes unreferenced Chrome chunks and deletion records that meet the retention and acknowledgement requirements. Reset Cloud From This Device replaces the cloud with active local links and starts a new collection generation.

Delete All requires typed confirmation and first saves a verified local backup. Removed links can therefore remain in a safety backup until backups are cleared or replaced. Tabel keeps at most five local safety backups with a total budget of 50 MiB. Checkpoints needed by unfinished recovery jobs are protected. Removing the extension removes its local data and local safety backups. Exported JSON files remain wherever the user saved them.

Cloud reset and Chrome Sync clearing are separate confirmed actions. Clearing Chrome Sync keeps a small reset marker and pauses an active Chrome provider. Older Tabel versions must stop syncing before Chrome cloud resets to avoid refilling the old storage.

8. Export and import

Export creates a JSON file only when requested. Import reads the selected file, validates it, asks for confirmation, and creates a verified safety backup before replacement. Restoring a safety backup is also a confirmed action and can synchronize changes to other devices. Exported files and local safety backups are not sent to the developer.

9. Security

Tabel uses official Chrome storage APIs, executes no remote code, and requests only the permissions required for its features.

10. Limited Use

The use of information received from Google APIs will adhere to the Google API Services User Data Policy and the Chrome Web Store User Data Policy, including the Limited Use requirements.

11. Policy changes

Material changes to data handling will be disclosed before they take effect. The date at the top of this page will be updated.

12. Contact

For privacy questions or requests, use the support page and the support channel on the Tabel Chrome Web Store listing.
