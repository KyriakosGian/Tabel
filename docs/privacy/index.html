Privacy Policy

Last updated: July 22, 2026

Tabel works without a Tabel account, advertising, or a developer-operated server.

1. Scope

This policy explains how the Tabel extension for Google Chrome collects, uses, stores, and shares data.

2. Data processed by Tabel

When a user chooses to organize open tabs, Tabel processes:

  • the URL of each selected tab
  • the page title and icon
  • user-created group names, sorting choices, and display preferences
  • extension settings such as theme and startup behavior

Tabel does not read passwords, cookies, form contents, or full webpage content.

3. When collection occurs

Tab data is read only after the privacy notice is accepted and the user clicks the Tabel icon. The extension does not continuously record browsing history.

4. Purpose

Data is used only to save, display, search, sort, sync, and restore the tabs that the user chooses to organize.

5. Storage and synchronization

Groups and tabs are stored locally in the browser using IndexedDB. Settings and temporary operational data are stored with chrome.storage.local. Saved data can sync between devices using chrome.storage.sync, which is managed by Google Chrome and the user's Google Account.

The Tabel developer does not operate an external server and cannot access stored or synchronized data.

6. Data sharing

Tabel does not sell, rent, or disclose data to advertisers, data brokers, or other third parties. Synchronization occurs only through the Chrome synchronization service.

7. Retention and deletion

Data remains stored until the user opens or deletes the relevant tabs, uses Delete All, or removes the extension. Synced data is also governed by the user's Google Chrome synchronization settings.

8. Export and import

Export creates a JSON file only when requested by the user. Import reads only the JSON file chosen by the user. These files are not sent to the developer.

9. Security

Tabel uses official Chrome storage APIs, executes no remote code, and requests only the permissions required for its features.

10. Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

11. Policy changes

Material changes to data handling will be disclosed before they take effect. The date at the top of this page will be updated.

12. Contact

For privacy questions or requests, use the support page and the support channel on the Tabel Chrome Web Store listing.
