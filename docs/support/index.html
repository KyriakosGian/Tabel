Support

Basic troubleshooting steps for Tabel.

Install Tabel

Install Tabel from the Chrome Web Store. Developer mode is not required.

The extension does not save tabs

  1. Open the Dashboard and accept the privacy notice.
  2. Make sure the page uses an eligible web address.
  3. When using Save Tabs, check the pinned-tab and audible-tab options in Settings.
  4. Restart Chrome and try again.

Data does not appear on another device

  1. Make sure Tabel is installed on both computers.
  2. Sign in to the same Google Account in Chrome and enable Chrome sync, including extension data.
  3. Open the Tabel Dashboard on both computers.
  4. Check sync quota usage in Settings. Chrome sync has approximately 100 KB available, including deletion records and metadata. If a sync write fails, saved tabs remain local.

The Settings label "Last successful sync" reports the last successful operation with Chrome's sync storage on this device. It does not confirm delivery to another computer. Check the Dashboard on the other computer to confirm that the saved data appears.

Create or restore a backup

Open Settings, choose Export Data, and save the JSON file in a safe location. Backups contain saved groups and tabs, not extension settings. Import Data asks for confirmation before replacing saved groups and tabs. Imported data can synchronize to your other devices.

Delete saved data

The Delete All button in Settings removes saved groups and tabs but keeps extension settings. Deletions can synchronize to your other devices. Export a backup first if you may need the saved tabs again.

Report a problem

Create a bug report on GitHub. Include the Chrome version, Tabel version, and the steps that caused the issue. Do not include private URLs or personal data.
