Support

Basic troubleshooting steps for Tabel.

Install Tabel

Install Tabel from the Chrome Web Store. Developer mode is not required.

The extension does not save tabs

  1. Open the Dashboard and accept the privacy notice.
  2. Make sure the page uses an eligible web address.
  3. When using Save Tabs, check the pinned-tab and audible-tab options in Settings.
  4. Restart Chrome and try again.

Data does not appear on another device

  1. Use Tabel 2.2.0 or newer on both computers, with the same Chrome account and extension data synchronization enabled.
  2. Save or import on one computer. Leave Chrome open on both devices. Use Sync now if needed.
  3. Check the saved-link count and receipt status. A local Chrome Sync write does not prove delivery to another device. Receipt confirmation requires the updated extension on the receiving device.
  4. If Settings offers Review recovery, compare the local and Chrome Sync copies. Choose the copy that contains your links and review the final confirmation. A verified backup is kept first.

Do not repeatedly reset or clear the cloud for an ordinary delay. Automatic checks run while Chrome is open.

Chrome Sync storage is full

Settings shows active local data, deletion history, metadata, and unused Chrome chunks. Deletion history remains for at least 90 days and until all known devices acknowledge it. Open Recovery tools to find Clean Unused Sync Data, which safely removes eligible history. For collections that exceed the Chrome Sync limit, choose Local Only and keep exported file backups. Reset Cloud From This Device recreates the cloud from this device's active links. Update or stop every older installation before a Chrome reset.

Clear Chrome Sync storage

After all devices have switched or stopped syncing, open Recovery tools and choose Clear Chrome Sync Storage, review the confirmation, type CLEAR, and acknowledge the other-device requirement. Local links remain. A small reset marker stays in Chrome Sync, and an active Chrome provider becomes Local Only.

A cloud collection was reset

If cloud data is missing or another device reset it, automatic uploads stop. Use Current Cloud Data to rejoin a reset collection, or rebuild it from a trusted device. Both actions require confirmation and a verified local backup.

Create or restore a backup

Open Settings, choose Sync & backups, then Export Data, and save the JSON file in a safe location. Backups contain saved groups and tabs, not extension settings. Import Data asks for confirmation before replacing saved groups and tabs. Imported data can synchronize to your other devices.

Delete saved data

Delete All shows the group and link counts and requires typing DELETE. A verified local backup is created before deletion. Restore Last Backup restores saved data as a new change that can synchronize to other devices. Safety backups stay on this device and are removed on uninstall, so export a JSON file for long-term storage. Clear Backups removes local safety copies and requires its own typed confirmation.

Report a problem

Create a bug report on GitHub. Include the Chrome version, Tabel version, and the steps that caused the issue. Do not include private URLs or personal data.
