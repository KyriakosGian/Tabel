Support

Basic troubleshooting steps for Tabel.

The extension does not save tabs

  1. Open the Dashboard and accept the privacy notice.
  2. Make sure the page uses an eligible web address.
  3. When using Save Tabs, check the pinned-tab and audible-tab options in Settings.
  4. Check chrome://extensions/ for errors.
  5. Click Reload on the Tabel card and try again.

Data does not appear on another device

  1. Sign in to the same Google Account in both Chrome installations and enable Chrome sync, including extension data.
  2. Check that both installations use the same Tabel version and extension ID. The ID for 2.0.0 is hmdklfckhfiobokdglandjdndgaefngd.
  3. Keep the Dashboard open on both computers while testing.
  4. Check the last successful sync and quota usage in Settings. Chrome sync has approximately 100 KB available, including deletion records and metadata. If a sync write fails, saved tabs remain local.

Upgrade from a 1.x test installation

Version 2.0.0 uses the official Chrome Web Store identity and separate storage. Export a JSON backup before replacing or reloading an old installation. Install 2.0.0 from a separate folder, import the backup on your primary computer, and verify the saved groups before removing the old copy. Import replaces saved data and can synchronize that replacement. Keep separate backups if your computers contain different data.

Create a backup

Open Settings, choose Export Data, and save the JSON file in a safe location.

Report a problem

Create a bug report on GitHub. Include the Chrome version, Tabel version, and the steps that caused the issue. Do not include private URLs or personal data.
