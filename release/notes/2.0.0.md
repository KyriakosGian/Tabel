# Tabel 2.0.0

Tabel 2.0.0 is now available publicly on the Chrome Web Store. This version adopts the official Store identity and improves saving, synchronization, and backup validation.

## Installation

[Add to Chrome](https://chromewebstore.google.com/detail/tabel-tab-manager/hmdklfckhfiobokdglandjdndgaefngd)

Install directly from the Store. Developer mode is not required. The attached ZIP is intended for development and testing, with setup instructions in the [Development section](https://github.com/KyriakosGian/Tabel#development).

## Changes

- Atomic capture, import, and sync merges reduce the risk of partial saves or conflicting database updates.
- Serialized sync operations and UTF-8 chunk sizing improve synchronization reliability.
- Backup and sync validation rejects malformed records and unsupported URLs before changing saved data.
- Import now requests confirmation before replacing saved data and accepts files up to 5 MB.
- Privacy, support, and Store documentation now describe current data access and synchronization limits.

## Synchronization and backups

Synchronization requires the same Google Account with Chrome sync enabled on each device. Different Google Accounts do not share Tabel sync data. Chrome sync has approximately 100 KB of storage, including deletion records and metadata. Use Settings to check quota usage and export local JSON backups before replacing or removing an installation.
