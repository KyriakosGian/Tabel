# Tabel 2.0.0

Tabel 2.0.0 adopts the official Chrome Web Store identity and improves saving, synchronization, and backup validation. The Store listing remains unpublished. This GitHub package is available for manual installation and testing.

## Changes

- Atomic capture, import, and sync merges reduce the risk of partial saves or conflicting database updates.
- Serialized sync operations and UTF-8 chunk sizing improve synchronization reliability.
- Backup and sync validation rejects malformed records and unsupported URLs before changing saved data.
- Import now requests confirmation before replacing saved data and accepts files up to 5 MB.
- Privacy, support, and Store documentation now describe current data access and synchronization limits.

## Upgrade from 1.x

The official extension ID is `hmdklfckhfiobokdglandjdndgaefngd`. Earlier test installations used a different ID, so their data does not migrate automatically.

1. Export a JSON backup from the old installation before replacing or reloading it. Back up every computer that contains different saved data.
2. Extract this ZIP into a separate folder and use Load unpacked in `chrome://extensions/`.
3. Verify the new extension ID and import the backup you want to keep on your primary computer. Import replaces existing saved data and can synchronize that replacement.
4. Install this version on other computers using the same Google Account with Chrome sync enabled.
5. Check your groups and tabs before removing the old installation. Keep your backups.

The public key identifies the extension, not a user's account. Different Google Accounts do not share Tabel sync data. Chrome sync has approximately 100 KB of storage, including deletion records and metadata. Use Settings to check quota usage and export local backups.
