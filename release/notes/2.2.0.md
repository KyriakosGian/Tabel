# Tabel 2.2.0

The Chrome Web Store update is pending submission to the existing [Store item](https://chromewebstore.google.com/detail/tabel-tab-manager/hmdklfckhfiobokdglandjdndgaefngd). Download the ZIP attached to this release to install the GitHub version or submit the Store update.

Settings now has four sections: General, Appearance, Sync & backups, and About. It uses the Dashboard's shared colors, typography, density, and page width. Appearance changes have a live preview. Saving preferences shows an unobtrusive Saved indicator. Project website, GitHub, release, support, and privacy links appear in the footer.

Everyday synchronization and backups are separate from recovery and deletion tools. Recovery compares the number of saved links in both copies before choosing a source, creates a verified backup, and cancels if the reviewed data changes.

Synchronization protects newly arrived imports from stale uploads and newer chunks from stale cleanup. Incomplete downloads remain pending, and background workers resume downloads after restarting. A successful local Chrome Sync write is distinguished from receipt confirmed by another updated device.

Validation covers 126 regression tests, a 39-link import with overlapping uploads, Settings navigation and saving, responsive layouts, and backup and recovery safeguards in Chrome. The installed extension also passes database migration, native Chrome storage, background alarm, and recovery checks in an isolated Chrome profile. These checks do not establish delivery between two signed-in computers through Google Sync.
