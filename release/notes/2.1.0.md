# Tabel 2.1.0

Tabel 2.1 adds safer synchronization and recovery, Chrome Sync storage controls, and protection against accidental Delete All.

The update uses the existing [Tabel Chrome Web Store item](https://chromewebstore.google.com/detail/tabel-tab-manager/hmdklfckhfiobokdglandjdndgaefngd).

- Choose Local Only or Chrome Sync.
- Recover from full Chrome Sync storage without losing local links.
- See upload/download status, pending changes, storage use, and deletion history.
- Clean unused data, rebuild a cloud collection, or clear old Chrome Sync storage.
- Type DELETE before Delete All. Verified local backups allow restoration after critical actions.
- Recapturing a saved URL keeps its identifier and reduces unnecessary deletion history.

Upgrade or stop all older installations before resetting Chrome Sync. Cloud reset generations prevent Tabel 2.1 devices from automatically restoring old records, but Tabel 2.0 does not understand this protocol.

Local safety backups remain on the device and are removed if the extension is uninstalled. Export JSON for a long-term backup.
